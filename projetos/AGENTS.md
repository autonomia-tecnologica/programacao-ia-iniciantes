# Regras para o assistente

Quem pede é iniciante em programação. Responda em português do Brasil, com frases curtas.

- Trabalhe só dentro desta pasta.
- Faça **uma coisa por vez** e a versão **mínima** primeiro.
- Para algo visual, crie **uma página web de um arquivo só** (`index.html`, com CSS e JavaScript dentro).
  Sem biblioteca externa, sem CDN, sem instalar nada, sem build.
- Não crie `.exe`, `.bat`, `.sh` nem programas para a pessoa rodar fora do navegador.
- Depois de cada mudança, diga em uma frase como a pessoa abre e testa.
- Ao pedido da pessoa, registre decisões e aprendizados em `notas/` em arquivos `.md`.
- Nunca peça nem grave senha, chave ou dado pessoal.
